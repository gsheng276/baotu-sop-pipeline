# 爆图 SOP 流水线

把"爆图工作台"的头部对标方法论搬成可复用仓库：**多图读取 → 6 维提炼 → 图片 SOP → 生图规则（含出图约束）**，用 Codex 直接跑。

## 用法（Codex）

1. 把待分析的图片放进 `input/<类目>/`（如 `input/抽象雕塑/`），一次放一组（Top10 主图或参考图）。
2. 对 Codex 说一句话（CLI 里可直接贴图）：

   ```
   按 AGENTS.md 流程，对 input/抽象雕塑/ 下的图片做完整三步，输出到 output/抽象雕塑/
   ```

3. 得到三个文件：
   - `output/<类目>/traits.json` — 6 维提炼数据
   - `output/<类目>/sop.md` — 可复用的图片 SOP
   - `output/<类目>/生图规则.md` — 生图提示词模板 + 出图约束

`prompts/` 下是三步各自的详细 prompt（Codex 会自动按 AGENTS.md 走，也可以单独取用）。

## 新开一轮

```bash
bash scripts/new_round.sh 抽象雕塑
```

自动建好 `input/抽象雕塑/` 和 `output/抽象雕塑/`。

## 方法论来源

- 6 维提炼框架：构图 / 背景 / 色调 / 灯光 / 文案 / 产品占比
- SOP 结构：通用骨架公式 + 分项规则 + 禁忌
- 生图规则：提示词模板 + 出图约束（固定项 / 可换项 / 禁止项）
- 实例见 `examples/抽象雕塑-sop.md`
