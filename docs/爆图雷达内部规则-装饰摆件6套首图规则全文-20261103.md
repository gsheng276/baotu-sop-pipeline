- **规则摘要**：以浅色低饱和家居空间为背景，将单件竖向深色摆件置于中轴承托面上，用顶部或侧上方暖光勾出轮廓与高光，四周保留大面积浅色留白，画面默认无文字和促销元素。成立条件是商品全貌与承托面完整入镜、主体与背景明暗对比清晰、道具不遮挡主体且不被表现为商品附件；本方法适合空间氛围与摆放效果表达，不替代细节、材质和尺寸证据。
- **表达目标**：让用户第一眼感知商品的空间气质和摆放方式，画面重心是单件主体的轮廓剪影与氛围，而非功能细节；空间感建立在竖向凹槽墙与中轴陈列上，主体与环境形成深与浅的对比。
- **构图与阅读顺序**：①竖向中轴构图：背景为竖向凹槽墙板，中央偏中轴承托面（大理石柱台或石质展台）；②商品置于画面纵向中轴偏上，主体与承托面构成"竖向雕塑陈列"关系；③光源从右上方或顶部斜射，在主体上形成暖色高光与柔和阴影；④背景左右两侧保留大面积浅色留白，无其他竞争性视觉元素；⑤前景可配少量浅色道具（如书本、干花），但不得遮挡主体。阅读顺序：背景竖向线条引导视线至中央主体 → 感知主体轮廓剪影与高光 → 视线下移至承托面与道具 → 最后感知整体空间氛围。
- **商品展示方式**：商品为单件，完整全貌可见，正面略偏3/4角度；高度约占画面高度三成至四成，宽度不超过画面宽度一成半，底部落在承托面中央偏中轴，接触处有真实投影；主体不被道具遮挡，承托面与主体保持清晰层次。若商品为细长型可保持竖向比例，宽体商品需缩放或改为更宽台面，不能挤满留白。
- **配色与视觉风格**：默认方案：浅暖灰或米白竖向凹槽墙为背景，浅灰白大理石柱台与地面；主体为黑色或深色半哑光或高光材质；光源从右上方或顶部斜射，呈暖黄或暖白，形成主体高光、柔和阴影和背景渐变；整体低饱和、干净、留白充足，默认无文字。可变范围为背景色相与质感、承托结构、光线方向和少量边缘道具，但必须保持浅色低饱和环境包围深色主体、竖向中轴、真实承托和清晰留白。
- **文字位置与作用**：默认画面不安排文字区。
- **所需素材**：①商品单件实物；②浅色低饱和竖向凹槽墙面；③大理石或石质承托台面；④暖色光源（右上或顶部）。
- **固定规则**：①单件主体，完整全貌；②竖向中轴构图；③浅色低饱和背景包围深色主体；④承托面真实接触；⑤道具不遮挡主体；⑥默认无文字；⑦留白充足。
- **可调整项与条件**：背景色相/质感、承托结构、光线方向、边缘道具可调，但须维持浅包深、中轴、真实承托、留白四要素。
- **复用限制**：仅适用于单件竖向摆件/雕塑陈列氛围表达；不替代细节、材质、尺寸证据；多件套、宽体商品需调整。
- **执行步骤**：①确认商品为单件竖向；②搭建浅色竖向凹槽背景；③放置承托台于中轴；④商品置于承托面中央；⑤布置右上暖光；⑥检查留白与遮挡；⑦确认无文字区。
- **检查要点**：主体完整入镜；明暗对比清晰；道具不遮挡；承托关系真实；留白充足；无文字。
- **适配信息**：适用品类：家居饰品＞摆件；家居饰品＞花瓶/花器/仿真花/仿真饰品＞花器/花瓶＞花瓶。适用平台：淘宝、天猫、京东、抖音电商、小红书电商。适配人群：①注重家居美学、愿意为设计感付费的年轻女性；②偏好轻奢、侘寂、现代中式风格的家装人群。经营目标：提高点击率、促进收藏加购、提高成交转化率、塑造品牌调性。

- **规则摘要**：以单件装饰摆件为唯一视觉中心、用极简画廊式家居空间衬托主体轮廓与质感。默认1:1方形画面、中央纵向轴、浅色低饱和室内背景、底座与浅色展台自下承托、右上方暖光塑造体积，保留大面积留白；不依赖文字、价格或促销元素。成立条件是主体轮廓完整、与背景保持最高对比，且表面效果、尺寸和台座关系均有真实商品依据。
- **表达目标**：让用户第一眼理解这是一件被精心陈列的单件装饰摆件，先感知其完整轮廓、表面起伏和高级家居陈设氛围，而不是读取参数或促销信息。画面通过居中、抬升、浅色留白和侧光建立艺术化展示语境，同时保持商品本体的最高识别度。
- **构图与阅读顺序**：①1:1方形画面，中央纵向轴；②主体居中，底座与展台自下承托；③浅色低饱和背景，大面积留白；④右上方暖光塑造体积。阅读顺序：先看到中央商品主体的完整轮廓和最高对比位置 → 沿主体曲线与受光凸面阅读表面起伏和材质质感 → 视线下移到黑色或深色底座、浅色展台，确认商品被抬高陈列 → 最后感知左右浅色留白、竖向背景线条、右上方暖光和地面投影。
- **商品展示方式**：商品主体位于画面中央纵向轴上，正面或轻微侧向展示，完整轮廓可见，底部与底座连接关系清楚。主体本体约占画面高度三成半至五成，连同底座和展台形成约六成纵向主体；横向占比按真实轮廓调整，但必须保持全画面最高对比和唯一视觉中心。台座直接位于主体下方，宽度和高度不得压过主体；商品不得被背景线条、阴影或配景遮挡。
- **配色与视觉风格**：默认低饱和暖灰、米白或浅石色现代室内背景，中央可带竖向凹槽墙板形成纵向秩序，地面为浅色平滑材质并保留柔和投影。整体明暗关系固定为浅背景衬托深色或高对比主体，光线从右上方柔和斜入，凸面出现高光，暗部保留体积。材质表现必须依据真实商品，深色高光只适用于确有相应表面处理的商品。大面积留白是画面成立条件，背景不能出现繁杂图案或同等重量的配景。默认画面无文字；任何文字信息应另配版式，不属于本方法核心画面。
- **文字位置与作用**：默认无文字区。
- **所需素材**：①单件商品实物；②浅色低饱和室内背景；③底座与展台；④右上暖光源。
- **固定规则**：①单件唯一视觉中心；②中央纵向轴；③浅背景衬托深色/高对比主体；④底座展台自下承托；⑤大面积留白；⑥默认无文字。
- **可调整项与条件**：背景竖向结构、底座材质、光线强度可调，但须保持最高对比与唯一中心。
- **复用限制**：仅适用于轮廓清晰、适合单件陈列的装饰摆件/雕塑；浅色、透明、扁平或小体量商品需通过深色底座、轮廓光或调整背景明度维持最高对比，否则不适用；不得沿用原图具体造型、层纹或高光作为新商品事实。
- **执行步骤**：①确认商品适合单件陈列；②搭建浅色背景与竖向结构；③放置底座展台；④商品居中放置；⑤布置右上暖光；⑥检查对比与留白；⑦确认无文字。
- **检查要点**：主体最高对比；轮廓完整；底座关系清楚；留白充足；无竞争性配景；无文字。
- **适配信息**：适用品类：家居饰品＞摆件。适用平台：淘宝、天猫、京东、抖音电商、小红书电商。适配人群：追求家居美学、注重设计感的消费者。经营目标：提高点击率、促进收藏加购、塑造品牌调性。
