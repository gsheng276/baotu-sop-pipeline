  - 单件完整展示商品
  - 单一主角，没有其他商品和人物

  - 商品轮廓与结构可以识别
  - 尺寸与版型符合实物
  - 主角商品占主画面，主体清晰无裁切
  - 商品结构可识别，细节真实清晰

  - 挂拍与实物长短不一致
  - 不能跨类目复用，不能改变商品身份。
  - 单件整裙看版型
  - 参考品牌、参数、交易条件和效果陈述不作为本品事实；按本品替换。
  - 灰蓝直筒裙腰头和口袋对应实物
  - 参考品牌、参数、交易条件和效果陈述不作为本品事实；按本品替换。

  4. 按检查要点逐项检查商品身份与真实性
  5. 检查无误后输出

  - 本品身份与售卖范围一致，不引入无关商品
