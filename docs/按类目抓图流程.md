# 按类目抓图流程（取数端）

> 说明：抓图需要登录用户淘宝后台（生意参谋/达摩盘）的浏览器环境，Codex 端跑不了，
> 由 Muse 这边执行。抓到的图按命名规范放进 `input/<类目>/`，再交 Codex 做三步提炼。
> 本流程 2026-10-30 实测走通。

## 数据源（二选一，按叶子所在定）

1. **生意参谋免费版**：顶栏「市场」→ 左侧「类目洞察」→ 页签「价格分析」
   → 每行价格带「操作」列点「商品发现」。
   - 限制：类目树只含店铺主营（本账号仅"住宅家具/家居饰品"两根），目标叶子不在树中即判无数据，不许近似替代。
   - 取"热销推荐价格带"的 Top10：排名/标题/商品ID/链接/支付单量/件单价（区间脱敏值）。
2. **达摩盘**：「市场榜单 NEW」（#!/compete/market-rank），榜单类型=销量明星、分析周期=近7天。
   - 一级类目 8 项：家居饰品、住宅家具、商业/办公家具、节庆用品/礼品、其他、
     家庭/个人清洁工具、餐饮具、饰品/流行首饰/时尚饰品新；子树为精简树
     （如"餐饮具"下仅"餐具>果盆/果盘/果篮"），叶子不在树中即判无数据。

## 主图提取

- 链接统一拼 `https://item.taobao.com/item.htm?id=<商品ID>`，必须实测可访问且标题与榜单一致。
- 淘宝主图无直链：详情页**存为 PDF** → `pdfimages -j -f 2 -l 2` 抽第 2 页图片
  → 取 ≥600×600 中最大文件即主图 → PIL 转 JPEG q88。
  （达摩盘榜单表内嵌图抽出为 0 字节，不可用，必须走详情页。）
- 单个商品打印失败**两次记缺失**，不再硬试；抽出全黑图/拦截页同样记缺失。

## 命名与存放

- 文件名：`排名-商品ID-简称.jpg`（如 `01-1057182739941-抽绳垃圾袋.jpg`）。
- 缺失项无文件，在 traits.json 里以 `"missing": "原因"` 标注。
- 放进 `input/<类目>/` 后，通知 Codex 按 AGENTS.md 跑三步。

## 纪律

- 全程只读：不改计划/出价/预算/启停，不订购付费功能，不点关注/收藏。
- 浏览器任务若打开无关站点登录页视为串线：不填账号密码，先报告再重派。
