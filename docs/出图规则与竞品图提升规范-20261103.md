# 出图规则与竞品图提升规范（2026-11-03 定版）

> 来源：2026-11-03 下午 4 链接果盘主图出图实战（Codex 按竞品 SOP 出图 + 逐张验图）。
> 用途：后续所有出图的引用规范。给 Codex 的指令只给一句话，md 里已有的要求不重复。

## 一、出图规则流程（9 项模板）

1. 主图统一 1:1（1440×1440）
2. 长×宽×高 + 形态关键词（浅盘 / 高脚 / 波浪）
3. 台面位置、产品位置占比、背景结构、留白分区
4. 颜色材质、形态、拍摄角度、盘内物、接触投影
5. 场景类型、道具（不抢戏）、氛围定位
6. 光源方向、光池、轮廓光
7. 低饱和、冷暖方向
8. 默认无文字；有文案时按文字大小限制（主标题字高≤6% 画面高、宽≤55%、顶部留白≥8%；副标题字高为主标题 60%；主标题≤10 字、副标题≤8 字）
9. 固定项（结构 / 颜色 / 比例 / 尺寸）+ 可换项（背景 / 灯光 / 道具）+ 禁止项（禁拉伸变形、禁改颜色结构、禁增减部件、禁悬浮、禁遮挡盘沿、禁编造信息）

## 二、竞品图提升规则（Codex 竞品 SOP 实证有效）

1. **实拍锚点**：出图必须喂实拍图，波浪节奏 / 结构以实拍为准。实证：R6014B 没锚点时画成深碗，有锚点后盘形一次对。
2. **尺寸进提示词**：30×30×8.5cm 这类实数写进，防比例失真。
3. **形态词双重强调**：浅盘 / 高脚同时出现在和（"禁把浅盘画成深碗""禁把高脚画成平底"）。
4. **词图配对**：标题场景词必须在主图有对应画面，无画面的词不进标题；主图换场景词路同步换。
5. **白款防白吃白**：背景加深一度 + 轮廓光，白色主体必须可分离。
6. **产品保真底线**：禁改色、禁变形、主体完整不裁切、表面效果服从实物、默认无文字、单主体。

## 三、提升提示词（img2img，呈现层专用）

> 以成图为基准，只动呈现层、不动产品本体（结构 / 颜色 / 比例 / 尺寸严格不变）。

**通用提升指令**：
```
以原图为基准做呈现层提升，产品本体（结构/颜色/比例/尺寸）严格保持不变：轮廓光勾勒产品边缘增强立体感；材质哑光质感渲染加强；背景虚化再推一档、主体更突出；道具精简去杂（只留1-2样）；光影过渡更柔和、投影更真实。禁改产品颜色结构、禁拉伸变形、禁增减部件。
```

**分场景提升要点**：
- 客厅茶几：右上暖光勾波浪边高光；茶几木纹质感加强；手部动作自然。
- 玄关：壁龛光池加强（上亮下暗层次分明）；波浪边暖色轮廓光更清晰。
- 商务会所：通透感提升；茶点色泽诱人但保持低饱和；背景虚化更柔。
- 奶油风：奶油色调统一柔和；高脚底座轮廓光加强；白盘与背景分离度拉开。
