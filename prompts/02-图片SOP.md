# Step 2 — 出图片 SOP Prompt

基于 Step 1 的 6 维提炼共性，写一份**可复用的图片 SOP**。固定结构如下，缺一不可：

## 1. 通用骨架（一句话公式）

把共性压缩成一个公式，格式：`A + B + C + D = 效果`。

示例：`单件雕塑 + 高底座展台 + 极简背景墙 + 定向光 = 艺术品陈列`

## 2. 分项规则

- **主体**：几件、占画面比例、摆放方式。
- **底座/陈设**：有无底座或展台、材质、高度占比；没有底座的类目写"无底座要求"。
- **背景**：给 2~3 个可选项（如"肌理水泥墙 / 木质壁龛 / 竖条纹墙板"），并写清共同点（纯色、大留白、零杂物等）。
- **灯光**：给 2~3 个可选项（如"顶部暖黄射灯 / 自然窗光斜射"），并写清共同点（光源方向明确、有明暗立体感等）。
- **色调**：饱和度要求、主色系。
- **构图**：居中/偏置、留白要求；是否允许人物入镜（允许则写清人物作用与着装要求）。

## 3. 禁忌

明确列出不许出现的东西，如：生活杂物、卖场式多件并排、高饱和色、正面平光、无底座直接放地面。

## 输出

`output/<类目>/sop.md`。语言精炼，每条规则一句话。
