# Step 3 — 生图规则 Prompt

基于 Step 2 的图片 SOP，生成**生图规则**，包含两部分，缺一不可：

## 1. 提示词模板

一段可直接填空的生图提示词。格式要求：

- 自然语言一段话，包含：主体描述 + 底座/陈设 + 背景 + 灯光 + 色调 + 构图 + 画质词。
- 可换变量用 `[中括号]` 标出，并给出选项，格式 `[选项A/选项B/选项C]`。

示例：

> 一件抽象[材质][形态]雕塑，立于[石材/木质/大理石]高展台上，背景为[肌理水泥墙/木质壁龛/竖条纹墙板]，[顶部暖黄射灯/自然窗光斜射]，低饱和中性色调，画廊陈列式构图，大量留白，摄影质感

## 2. 出图约束（必须有）

分三块写：

- **固定项**：产品本体结构（如"金色球头 + 白色碎片质感人形 + 云朵状白底座 + 圆形石材展台，四件套缺一不可"）、颜色（精确到"通体白、球头镜面金"）、关键比例。**能量出数字就能量**（如"球头直径 : 人体高 ≈ 1 : 5.5"、"云底座宽 : 展台直径 ≈ 1 : 1.35"）；量不出就写"以参考图为准"，不许编数字。
- **可换项**：背景、灯光、底座材质等场景元素。
- **禁止项**：禁拉伸变形、禁改产品颜色结构、禁增减部件（再加本品特有的，如"禁球头变形或变色"）。

## 输出

`output/<类目>/生图规则.md`，结构：`## 提示词模板` + `## 出图约束`。
