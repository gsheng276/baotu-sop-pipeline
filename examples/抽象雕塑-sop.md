# 实例：抽象雕塑 SOP（2026-10-30 实产）

来源：淘宝装饰摆件类目 4 张头部参考图（家居装饰人群），按本仓库 AGENTS.md 三步流程产出。

## 通用骨架

**单件雕塑 + 高底座展台 + 极简背景墙 + 定向光 = 艺术品陈列**

## 分项规则

- **主体**：单件抽象雕塑，画面唯一主角，占画面高度约 1/3~1/2，不堆多件。
- **底座**（4/4 必备）：石材 / 木质 / 大理石高展台，高度约画面 1/4~1/3。作用是把"商品"抬成"艺术品"，生图时必须写进提示词。
- **背景**（三选一）：肌理水泥 / 艺术漆墙、木质壁龛、竖条纹或纯色墙板。共同点：纯色、大面积留白、零生活杂物。
- **灯光**（三选一）：顶部暖黄射灯打亮主体、自然窗光斜射（地面带光影）、柔和漫射 + 局部高光。共同点：光源方向明确、雕塑有明暗立体感；忌正面平光。
- **色调**：低饱和中性色（白/黑/灰/木/米），雕塑与背景同色系，或黑白对比。
- **构图**：居中或微偏置，上下大留白。可加人物作尺度参照（仅限轻触互动、不抢主体、浅色宽松服装）。

## 禁忌

生活杂物、卖场式多件并排、高饱和色、正面怼脸平光、无底座直接放地面。

## 生图提示词模板

> 一件抽象[材质][形态]雕塑，立于[石材/木质/大理石]高展台上，背景为[肌理水泥墙/木质壁龛/竖条纹墙板]，[顶部暖黄射灯/自然窗光斜射]，低饱和中性色调，画廊陈列式构图，大量留白，摄影质感

## 出图约束（白色金球头款实例，比例已实测）

- **固定项**：金色球头 + 白色碎片质感人形 + 云朵状白底座 + 圆形石材展台，四件套缺一不可；球头直径 : 人体高 ≈ 1 : 5.5；云底座宽 : 展台直径 ≈ 1 : 1.35；通体白、球头镜面金。
- **可换项**：背景、灯光、展台石材纹理。
- **禁止项**：拉伸压扁、球头变形或变色、云底座改形、增减部件。
